# MangaShelf downloads

Installers and updates for MangaShelf, a manga and manhwa reader for Windows 10/11.

## Install

1. Open the [latest release](https://github.com/JustSad42/mangashelf-releases/releases/latest).
2. Download the file ending in `_x64-setup.exe` and run it.
3. If Windows says *"Windows protected your PC"*, click **More info**, then **Run anyway** (the app is not code-signed).

The first start asks where to save chapters and offers to download the upscaler.

## Updates

MangaShelf updates itself. When a new version is out, an **Install** button appears at the bottom of the sidebar.

The release named **Plugins** is used by the app for automatic site fixes; you never need to download it.
